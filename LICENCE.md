## 🧩 About

**Rocket League overlay** is a curated list of Rocket League open-source tools:

- **Overlays** — on-screen helpers, layout notes, boost tracker, ball indicator
- **Quality-of-Life Helpers** — replay manager, camera settings, overlay notes
- **Research Notes** — training packs and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize ball and car hitboxes
- Replay Notes — record and review match runs
- Playback Speed — adjust training playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse wheels, decals, boosts, trails
- Custom Skin Notes — organize car cosmetics
- Ball Trail — improved ball visibility

### 🏋️ Practice Layout
- Training Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-match
- Jump Buffer Notes — chain complex maneuvers in free play

## ⚙️ Configuration

| Parameter | Type | Default | Description |

| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
